# AceMode

> 团队视频智能制作助手

AceMode 是一个面向个人创作者的 AI 辅助视频生产桌面工作台。

它希望把内容准备、AI 主持、真人录制、基础后期、审片和导出放在同一个工作空间中，同时确保原始素材安全、版本关系清楚，并由创作者决定最终发布什么。

## 当前状态

项目处于一期产品验证阶段。

目前已完成：

- 一期详细产品方案评审；
- 桌面客户端方向确认；
- 第一版可交互界面原型；
- 核心创作流程和一期边界初步收敛。

当前界面原型：

- [acemode-desktop-prototype.html](./acemode-desktop-prototype.html)

直接使用浏览器打开该文件即可体验。原型只用于验证信息架构和交互，不会访问摄像头、麦克风或云端服务，也不会生成真实视频。

## 产品形态

AceMode 采用“桌面客户端 + 可选云端 AI 服务”的形式：

- 桌面客户端负责设备访问、本地录制、媒体保存、恢复、预览和导出；
- 云端能力负责选题、稿件生成、AI 主持语音、语音识别等可降级服务；
- 本地保存是主链路，云端服务中断不能破坏正在录制的原片。

界面采用三栏工作台结构：

1. 左侧管理作品、原片和全局设置；
2. 中间承载 AI 协作、录制、审片等当前任务；
3. 右侧持续展示稿件、问题单、来源等实际产物。

## 一期核心流程

```text
输入想法
  → 生成并修改稿件
  → 确认主持问题单
  → 设备预检
  → AI 按问题单提问、真人回答
  → 重录或选择有效 Take
  → 固定模板生成预览
  → 修改字幕并审片
  → 导出视频与发布材料
```

## 一期范围

一期优先实现：

- 单创作者、单作品工作流；
- 稿件与问题单的生成、编辑、确认和版本记录；
- 一套明确支持的系统、设备和音频路由组合；
- 真人视频、本人音频和 AI 主持音频的可靠保存；
- 按题重录、候选 Take 和有效 Take 选择；
- 固定模板成片、字幕修正、人工审片；
- MP4、字幕、发布文案和项目清单导出；
- 断网、设备异常、磁盘写入失败和应用异常退出的可见状态与恢复边界。

一期暂不实现：

- 写实数字人和声音克隆；
- 无边界自由追问；
- 完整时间线剪辑器；
- 自动跨平台上传与发布；
- 多租户、组织权限和复杂计费；
- 企业知识库或大规模素材管理平台。

## 核心产品原则

- **本地优先**：云端服务不可用时，仍要保护本地原片和已有成果。
- **产物优先**：AI 对话用于协作，稿件、问题单、录制和成片才是可管理对象。
- **版本不可覆盖**：确认后的内容、历史录制和旧成片必须可以追溯。
- **人工最终确认**：内容确认、录制授权、成片审核和平台发布是不同动作。
- **失败必须可见**：未保存、缺失、处理中和失败不能伪装成成功。
- **最小数据外发**：没有明确授权时，不向第三方服务发送真实素材。

## 开发前待确认

正式进入实现前，需要在 M0 阶段确定：

- 首期支持 macOS、Windows，还是其中一个平台；
- 桌面技术栈及媒体处理方案；
- 首期支持的摄像头、麦克风和音频路由组合；
- AI 主持声音是否进入最终成片；
- 分段落盘方式及异常退出时可接受的尾段损失窗口；
- 云端服务、预算、数据范围和素材授权；
- 项目负责人、音视频负责人、测试负责人和验收人。

## 计划中的仓库结构

技术选型冻结后再创建实际工程目录。预期可按职责组织为：

```text
apps/          桌面客户端
packages/      共享领域模型、协议和工具
tests/         回放、集成、媒体与端到端测试
docs/          产品、架构、决策和交付说明
fixtures/      获得授权或合成的测试素材
```

不要仅为了匹配这份示意结构提前建立空目录。
